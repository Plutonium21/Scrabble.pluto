Put your legally obtained Collins 2019 word-list text file in this folder.
Recommended filename: data/words.txt
The loader reads .txt files in data/ automatically (except this README).
Keep the source file locally; it is not bundled in this ZIP.
If the file is one word per line, ideal. Whitespace-separated lists are also
accepted. The loader extracts alphabetic tokens and uppercases them.
Check the file manually if it contains headers, page numbers, or definitions:
the parser may otherwise treat headings/definitions as words.
Do not publish or redistribute the Collins list unless your licence permits it.
